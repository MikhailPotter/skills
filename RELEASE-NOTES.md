# Release notes

## v0.1.0

The first release packages Problem, Plan, Execute, and Review together with their shared independent review helper. Each stage produces a Markdown handoff that can be used in a fresh conversation.

If you installed the initial five skills from `main`, the skill files are identical in this release. Existing plans and handoffs need no migration.

The [installation guide](README.md#install) includes a command to list the installed skills and a draft-saving example. The repository now includes an MIT license and checks pull requests by installing their contents into an empty project.
